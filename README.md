# Shipping Provider Integration

This repository contains the canonical **Shipping Provider Integration Skill** (`.ai/skills/shipping-provider-integration`) used for building and integrating new shipping couriers into Uniware.

---

## 🤖 How to Use the AI Skill

This skill works across AI coding agents (Antigravity, Cursor, Claude Code, Kiro, etc.).

### Step 1: Tell your AI Agent to load the skill

In your AI Agent chat, copy-paste the following prompt along with your Jira ticket and API documentation:

```text
Use the canonical Shipping Provider Integration skill:

.ai/skills/shipping-provider-integration/SKILL.md

Read the skill and its supporting knowledge/rules/templates before doing anything else.

I will provide:
1. Jira ticket (pasted below)
2. Provider API documentation (pasted below)

Analyze the integration using PHASE A only.
Do not generate production artifacts yet.
After the analysis, stop and wait for my approval.

--- JIRA ---
<Paste your Jira ticket here>

--- API DOCUMENTATION ---
<Paste API documentation or endpoints here>
```

---

### Step 2: Approve & Generate Artifacts (Phase B)

Review the Phase A analysis and `IntegrationSpec` generated by the AI agent. Once approved, respond in the chat:

```text
Phase A is approved.

Proceed to PHASE B for this integration.

Generate the artifacts into: shipping-provider-integrations/<PROVIDER_CODE>/

Do not apply any database changes directly.
```

## 📂 Repository Structure

- `.ai/skills/shipping-provider-integration/`
  - `SKILL.md`: Main AI workflow instruction set
  - `README.md`: Full Developer Guide & Documentation
  - `rules/`: Integration rules (db, script, connector, source, status mapping)
  - `schemas/`: JSON schemas for validation
  - `templates/`: Code templates (`db.sql`, `db.js`, scraper XML templates)
  - `knowledge/`: Architecture & field mappings reference
